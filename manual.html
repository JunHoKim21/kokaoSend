✨ 프로그램 소개

다락방 말씀 알림이란?

수많은 공지가 쏟아지는 단체 카톡방과 달리, 순원의 이름을 직접 부르며 전하는 1:1 메시지는 마음을 열고 깊은 은혜를 나눕니다.
다락방 말씀 알림이는 다락방 순장님들이 매주 반복해서 보내던 맞춤 말씀, 나눔 질문, 주보 공지, 사진을 단 한 번의 클릭으로 각 순원에게 1:1 개별 전송해 드리는 윈도우 전용 프로그램입니다.

👤

1:1 맞춤형 이름 치환

본문에 {이름}을 넣으면 각 순원의 이름으로 쏙 자동 변경되어 발송됩니다.

🖼️

사진 + 글 동시 전송

말씀 카드 프리셋이나 소장 사진을 첨부하면 카카오톡으로 사진과 본문이 함께 깔끔하게 전송됩니다.

📦

100% 무설치(포터블)

Node.js, Python 등 복잡한 프로그램 설치가 전혀 필요 없이 더블 클릭 하나로 즉시 실행됩니다.

🚀 빠른 시작

초간단 3초 실행 방법 (무설치)

복잡한 설치 과정이 없습니다. 아래 3단계만 따라 하시면 바로 사용하실 수 있습니다.

1

PC 카카오톡 실행 및 로그인

사용 중이신 컴퓨터에서 PC 카카오톡을 켜고 평소처럼 로그인해 둡니다. (창이 최소화되어 있어도 괜찮습니다)

2

KakaoNotifier.exe 더블 클릭

폴더 내의 KakaoNotifier.exe (응용 프로그램)를 더블 클릭합니다.

3

전용 창이 열리면 사용 시작!

주소창이나 복잡한 탭이 없는 깔끔한 전용 데스크톱 창이 자동으로 열리며, 바로 다락방 순원들을 선택하고 발송할 수 있습니다.

💡
바탕화면 바로가기 팁: KakaoNotifier.exe 파일에 마우스 우클릭 ➔ [더 많은 옵션 표시] ➔ [보내기] ➔ [바탕 화면에 바로 가기 만들기]를 해두시면 매주 바탕화면에서 한 번에 켜실 수 있습니다.
👥 명단 관리

다락방 순원 명단 관리

다락방 그룹을 여러 개 운영할 수 있으며, 엑셀이나 카카오톡 대화 내용에서 복사한 명단을 한 번에 등록할 수 있습니다.

📋 엑셀 / 카톡 복사로 일괄 등록하기 (강력 추천!)

화면 좌측 상단의 [명단 일괄 등록 (엑셀/카톡 복붙)] 버튼을 누르고, 카카오톡 공지나 엑셀에 적힌 명단을 그대로 복사해 붙여넣으면 이름과 직분을 자동으로 분석하여 한 번에 등록해 줍니다.

// 지원하는 입력 예시:
김준호 순장
은경이 순원
박수현 010-1234-5678 부순장
최민재, 한소희, 임태훈

➕ 직접 한 명씩 추가하기

좌측 하단의 입력창에 순원 이름을 적고 직분(순원, 순장, 부순장 등)을 선택한 뒤 [직접 추가] 버튼을 누르면 즉시 명단에 추가됩니다.

➔ 전송: "안녕하세요 김준호 순원님! 이번 주 [1다락방] 모임 안내드립니다."

🖼️ 사진 & 성경 구절 활용

  • [은혜 카드 프리셋]: 따뜻한 캘리그라피 말씀 카드가 내장되어 있어 원클릭으로 선택할 수 있습니다.
  • [내 사진 첨부하기]: 주보 포스터나 직접 찍은 모임 사진을 간편하게 첨부할 수 있습니다.
  • [성경 구절 추천]: 위로, 평안, 감사, 축복 등 테마별 인기 구절을 본문에 즉시 삽입할 수 있습니다.
  • [카톡 미리보기]: 실제 카카오톡 노란색 대화창에서 어떻게 보일지 미리 확인해 볼 수 있습니다.
⚡ 발송 가이드

카카오톡 안전 발송 요령

안전하고 오발송 없는 개별 메시지 전송을 위한 팁입니다.

🔍 카카오톡 순원 검색 & 1:1 대화방 자동 전송

카카오톡에서 각 순원의 이름을 자동으로 검색하여 1:1 대화방을 열고 사진과 맞춤 메시지를 안전하게 전송합니다.

💡 사전 테스트 팁: 전체 발송 전, 순원 명단에 본인 이름(카톡 '나와의 채팅')을 추가하여 먼저 시험 발송해 보실 수 있습니다.

⏱️ 발송 속도 모드 & 대량 발송(500명 이상) 안전 수칙

발송 패널의 [⚡ 쾌속 0.5s] 및 [🛡️ 안전 1.5s] 버튼(또는 상단 헤더 스위치)으로 전송 속도를 간편하게 조절할 수 있습니다:

⚡ 소규모 쾌속 모드 (0.5초)

10~30명 다락방 단위 발송 시 기다림 없이 빠른 발송 권장

🛡️ 대량 안전 모드 (1.5초)

50명~수백 명 발송 시 카카오톡 스팸 제재(계정 차단) 방지용 필수

🚨 500명 이상 대량 발송 시 필수 안전 수칙:
카카오톡 서버는 짧은 시간에 수백 명에게 기계적 속도로 메시지를 연속 전송하면 스팸 계정으로 판단하여 24시간~수일간 이용 정지(보호조치)를 내립니다. 500명 이상 발송 시에는 반드시 [🛡️ 안전 1.5s] 모드를 사용하시고, 50~100명씩 끊어서 5~10분 휴식을 두고 분할 발송하십시오.
⚠️
발송 중 절대 주의사항:
발송 시작 버튼을 누르면 마우스와 키보드가 자동으로 움직여 카카오톡 대화방을 열고 사진과 글을 전송합니다.
전송이 진행되는 중에는 마우스나 키보드를 만지지 마십시오. (마우스를 건드리면 포커스가 어긋날 수 있습니다)
발송을 멈추고 싶으실 땐 화면 우측의 빨간색 [전송 일시 중지] 버튼을 누르시면 안전하게 멈춥니다.
❓ FAQ

자주 묻는 질문

Q. Node.js나 Python 같은 프로그램을 따로 설치해야 하나요?

전혀 설치하실 필요 없습니다! KakaoNotifier.exe 파일 안에 모든 구동 엔진이 완벽하게 내장되어 있어, 더블 클릭만으로 어떤 윈도우 컴퓨터에서든 즉시 실행됩니다.

Q. 프로그램을 껐다 켜면 등록해 둔 순원 명단이나 글이 지워지나요?

아닙니다. 안전하게 영구 저장됩니다. 컴퓨터를 재부팅하거나 앱을 껐다 켜도 입력하신 순원 명단, 그룹, 작성 중이던 메시지가 브라우저 전용 데이터 영역에 안전하게 보존됩니다.

Q. "카카오톡 창을 찾을 수 없습니다"라는 오류가 나와요.

컴퓨터에 PC 카카오톡이 켜져 있고 로그인되어 있는지 확인해 주세요. 카카오톡이 작업표시줄에 최소화되어 있어도 프로그램이 자동으로 화면 앞으로 띄워 발송합니다.

Q. 사진과 텍스트가 순서대로 잘 전송되나요?

네! 첨부하신 사진이 먼저 카카오톡 채팅방에 업로드된 후, 곧이어 1:1 맞춤형 본문 말씀이 순차적으로 깔끔하게 발송되고 창이 닫힙니다.
